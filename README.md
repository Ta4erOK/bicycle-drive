# Лабораторная работа № 5 — ООО «ВелосипедДрайв»

Демонстрационный экзамен, вариант В2, модули 1–2.

## Задание

1. Спроектировать базу данных (3 нормальная форма, ссылочная целостность) для магазина по продаже велосипедов.
2. Подготовить и импортировать данные заказчика (`Приложение_2_Данные_для_импорта`).
3. Построить ER-диаграмму (PDF).
4. Построить блок-схему алгоритма по ГОСТ 19.701-90 (PDF).
5. Разработать приложение (WPF, C#) с авторизацией, ролями и списком товаров согласно руководству по стилю.
6. Подготовить отчёт со скриншотами корректной работы системы.

## Структура репозитория

| `db/` | Скрипты базы данных: структура (`schema.sql`) и данные (`data.sql`) |

| `docs/` | ER-диаграмма, блок-схема, отчёт |
